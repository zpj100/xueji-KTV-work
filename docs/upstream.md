## 跟踪方式

- **代码更新**：以上游 `feature/igeba-media` 分支的提交为准。
- **版本发布**：以上游 Release 标签为准（如 `2.1.7`）。
- **曲库更新**：上游内置 `app/src/main/assets/igeba_catalog.db`（离线曲库分片）。
